# cards/retired/

Example cards built on compositions the editor no longer offers.

Round 1 judged 135 designs one at a time and rejected six compositions outright —
Corner, Inset Panel, Oversize, Quiet Pair and Sequence were dropped in every one of
the nine themes they appeared in, and Reversed Field survived only three. The
reasons are in `../verdicts/round-1.json`.

These files still load and still render correctly, because a saved card carries its
own layer stack rather than a reference to a composition. They are kept because a
rejected design is evidence: it is much easier to argue about whether retiring
something was right when you can still look at it.

Nothing here is a live example. The current set is one directory up.
