# Holder photos

Drop a photo in here named `<slug>.jpg` and the matching body on the page swaps its
line drawing for the real thing automatically — in the card grid and in the detail
sheet. No code change, no rebuild. If a file is absent the drawing stays, so a
partial set is fine.

## What's in here now — placeholders, unverified licence

All fifteen files are merchant or manufacturer product photography, pulled from retail
listings and normalised to 900×675. **No reuse permission was established for any of
them**, so treat the whole set as unverified licence and swap each one out as your own
sample photos arrive. This repo is public and served on GitHub Pages, so that swap is
the point, not a nicety.

Several came from a different listing than the brief named, either because the named
page was bot-blocked, or because its photography carried pack-size badges and seller
branding across the product. The filename and the product category are what the page
cares about, so substituting was free.

Two known compromises: `wall-plaque` sits on dark wood rather than the light background
the rest use, because it was the only badge-free frame that reads as a wall mount at
card size; and the four Seritag/NIUBEE sources are natively 500 px, so those files are
upscaled and slightly soft up close.

To preview a photo before committing it, open the page, click a body, and use
"Attach a photo" — it loads locally for that session only.
